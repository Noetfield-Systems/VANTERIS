# Client hub v2
Customer dashboard separates overview, projects, tasks, proposals, agreements, invoices, payments, appointments, messaging/support, requests, documents, specialists and notifications. The client hub API derives scope from the existing hashed access token; only authorized operators can create agreements, assign specialists, publish documents, send notifications and change delivery plans. Agreements preserve seller, exact terms, version, name and acceptance timestamp; this is recorded electronic acceptance, not certified digital signature. Direct offers remain available independently. Documents are private database-backed text records only; no binary upload or ID document support. No external email notifications, full MFA or encryption-at-rest guarantee is claimed. Project plan records owner, due date, criteria and dependencies. Real production database and migration remain required.
