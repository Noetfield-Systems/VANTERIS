# Technical architecture
Next.js App Router / React / TS → server API → PostgreSQL. Catalog data drives pages and routing. Public intake and booking validate inputs, parameterized SQL and atomic reservation. Operator bearer token is initial single-role access; client tokens hashed and scoped to lead ID. Stripe sessions server-priced; webhook signature, amount, currency, reference and event id checked. Future: managed auth with staff roles, tenant policies, secure storage, queue/outbox, job monitoring, idempotency keys and refund ledger. Independent environment and schema. No client records in Git. Deployment: CI test/build → dedicated host/DB → migrate → smoke tests → monitor. RPO/RTO targets must be agreed after backup capability is verified.
