# Customer journey
Discovery via sector content → objective/industry selector → service detail → enquiry or actual slot → qualification → proposal → explicit acceptance → contract/invoice → provider checkout → signed webhook → delivery → acceptance → renewal. Owner at each transition: growth, BD, advisory, finance, delivery, success. Recovery: unavailable slots offer enquiry; failed form retains entered data; declined payment remains pending; external dependencies tracked separately; refunds reconciled. Acceptance: trace each transition by lead ID and event, no false confirmation.
