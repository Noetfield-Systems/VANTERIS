# API map
GET /api/health: DB readiness. POST /api/lead: validated enquiry. GET/POST /api/booking: actual available slots and reservation. POST /api/checkout: server-priced session. POST /api/webhook: signature verified settlement. GET/PATCH/POST /api/operator: authorized CRM, projects and partners. GET/POST /api/operations: slots, proposals, portal issuance/revocation. GET/POST /api/portal: scoped client records and acceptance. GET /api/resources/:id: text checklist. Statuses: 200/201 success, 400 validation, 401 auth, 404 missing, 409 conflict, 503 unavailable. Never log tokens. Add OpenAPI schema and integration tests for all endpoints before versioned public API claim.
