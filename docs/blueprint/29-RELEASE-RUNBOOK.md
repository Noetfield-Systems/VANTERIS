# Release runbook
Portable Dockerfile and Compose configuration use dedicated PostgreSQL persistent volume, no exposed database port, and local-only web port until HTTPS reverse proxy is configured. Provide strong DB credentials in local secret configuration, URL-encode password in DATABASE_URL, use hostname db. Do not use CI fixture credentials. Run docker compose up --build; verify /api/health. Production host needs HTTPS, secrets, backups and service monitoring. No host was provisioned by adding these files.
Browser acceptance: Playwright Chromium at 360,390,768,1280,1440 widths, verify no horizontal overflow, mobile/desktop navigation, routing and consultation; save full-page screenshots as CI artifacts. This tests functional rendering, not human aesthetic parity or accessibility certification.
Release sequence: test branch → merge tested commit → deploy dedicated environment → migration → smoke test → configure actual availability → verify legal seller and commerce → provider test → live checkout. Maintain noindex for private routes. Rollback app to last verified version; assess schema compatibility before rolling back data. Keep all records isolated.
