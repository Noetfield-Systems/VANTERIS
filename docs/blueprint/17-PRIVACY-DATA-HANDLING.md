# Privacy and data handling
Collect only needed enquiry fields, consent and scoped project records. Separate customer data from public repository and other ventures. Private DB, TLS, least privilege, scoped access, token hashes, expiry and revocation. No credentials in logs. Define actual controller, contact, purpose, lawful basis, retention, subprocessors and transfer disclosures before live operations. Handle access/correction/deletion requests with identity verification. Draft legal policy requires jurisdiction-specific review. Production requirements: RBAC, staff MFA, rate limits, backups, restore drills, private document storage and audit review.
